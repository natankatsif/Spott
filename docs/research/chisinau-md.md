**Дата исследования:** 25 сентября 2026  
**Автор:** Antigravity Agent  
**Цель:** Определить архитектуру, форматы, объёмы и легальные способы сбора нормативных правовых актов муниципия Кишинэу (децизии CMC, диспозиции Примара) в условиях запрета в `robots.txt` (`Disallow: /`).

## 1. Ключевые выводы (Executive Summary)

1. **`chisinau.md` не хранит современные акты на своих серверах.**  
   Страницы разделов [Decizii CMC](https://www.chisinau.md/ro/decizii-cmcacte-locale-20926.html) и [Dispoziții](https://www.chisinau.md/ro/dispozitii-acte-locale-20923.html) прямо заявляют: *«Deciziile CMC / Dispozițiile primarului automat sunt preluate din registrul de stat a actelor locale actelocale.gov.md»* и содержат `<iframe>`, транслирующий виджет из государственной системы `actelocale.gov.md`.
2. **Первоисточником является ГИС «Registrul de stat al actelor locale» (`actelocale.gov.md`).**  
   Портал ведётся Государственной Канцелярией Республики Молдова (Cancelaria de Stat). В нём зарегистрировано **22 850 актов Кишинэу**:
   - **3 931** децизий Муниципального совета Кишинэу (CMC, `apl=19323`, `act_types=1`).
   - **18 919** диспозиций Генерального примара (`apl=18413`, `act_types=2`).
3. **Оба домена (`chisinau.md` и `actelocale.gov.md`) блокируют стандартных поисковых роботов через `robots.txt` (`Disallow: /`).**  
   Краулинг без согласования нарушает правила роботов обоих сайтов. Sitemaps отсутствуют (`/sitemap.xml` возвращает 404).
4. **Обнаружен структурированный DataTables API на `actelocale.gov.md`.**  
   Эндпоинт `POST https://actelocale.gov.md/ral/search/search_request` отдаёт данные с серверной пагинацией (`iDisplayStart`, `iDisplayLength`), фильтрацией по APL и типам актов, возвращая полные метаданные (номер, дата, название, статус законности, ID документа и ссылку на PDF).
5. **Архивные акты (до конца 2022 года) на `chisinau.md` представляют собой растровые сканы.**  
   PDF-файлы из архива `chisinau.md` (`/upload/.../*.pdf`) содержат изображения без текстового слоя (`/Font: False`, объём 2–5 МБ на документ), что потребует OCR при индексации архивной части.

## 3. Формат публикаций и объёмы данных

### 3.1. Объёмы данных в `actelocale.gov.md`
| Категория | APL ID | Тип акта | Общее кол-во актов | Период публикации |
|---|---|---|---|---|
| **Consiliul Municipal Chișinău (CMC)** | `19323` | `type=1` (Decizii) | **3 931** | 2019 — н.в. (активно пополняется) |
| **Primarul General al Mun. Chișinău** | `18413` | `type=2` (Dispoziții) | **18 919** | 2019 — н.в. (активно пополняется) |
| **Итого современный корпус:** | — | — | **22 850** | — |

Темп публикаций:
- Диспозиции Примара: ~200–400 актов в месяц.
- Децизии CMC: ~30–80 актов за сессию (сессии созываются 1–2 раза в месяц).

### 3.2. Формат файлов
- **Архив до 2022 (`chisinau.md`):** Сканированные PDF (разрешение ~300 DPI, без текстового слоя OCR). Для парсинга требуется модуль OCR (Tesseract / EasyOCR).
- **Реестр `actelocale.gov.md`:**
  - Каждый акт имеет карточку: `https://actelocale.gov.md/ral/act/<slug>-<act_id>.html`.
  - Скачивание документа: `https://actelocale.gov.md/ral/act/downloadAct/<file_id>/<act_id>`.
  - Форматы: преимущественно PDF (как текстовые цифровые PDF, так и сканированные копии с подписями и гербовыми печатями).

### 3.3. Метаданные актов
В структуре ответа доступны следующие поля:
- Идентификатор акта (`act_id`, например `2314793`).
- Название и предмет (`Cu privire la executarea hotărârii...`).
- Номер акта и дата принятия (`6/48 din 30.07.2026`).
- Орган власти (`Consiliul municipal Chisinau` / `Primarul general`).
- Юридический статус (`Act în vigoare` / `Abrogat`).
- Контроль законности (`Act legal` — виза территориального бюро Госканцелярии).
- Дата публикации в реестре (`data`).

## 4. Скрытые и публичные API

### 4.1. Внутренний AJAX API поиска `actelocale.gov.md`
Фронтенд портала использует jQuery DataTables, обращающийся к:
```http
POST https://actelocale.gov.md/ral/search/search_request
Content-Type: application/x-www-form-urlencoded
```

**Параметры запроса:**
- `apl`: Идентификатор органа (`19323` для CMC, `18413` для Примара).
- `type[]`: Тип акта (`1` — Decizii, `2` — Dispoziții).
- `iDisplayStart`: Смещение пагинации (0, 25, 50, ...).
- `iDisplayLength`: Размер страницы (например, 25 или 100).
- `sEcho`: Счетчик запроса DataTables (целое число).
- `text_search_input`: Текстовый поисковый запрос (опционально).

**Пример ответа:**
```json
{
  "sEcho": 1,
  "iTotalRecords": 3931,
  "iTotalRecordsText": "acte administrative",
  "iTotalDisplayRecords": 3931,
  "aaData": [
    [
      "<div class=\"document_item \">...<h5><span class=\"color1\"><b>Decizie</b></span>: <a target=\"_blank\" href=\"https://actelocale.gov.md/ral/act/cu-privire-la-...-2314793.html\">6/48 din 30.07.2026 - Cu privire la...</a></h5>...</div>"
    ]
  ]
}
```

### 4.2. Государственный портал открытых данных (`date.gov.md`)
Попытка обращения к CKAN API `https://date.gov.md/api/3/action/...` в настоящее время возвращает страницу технического обслуживания (`maintenance.itsec.md`). Прямой открытый выгружаемый датасет по актам местного самоуправления на `date.gov.md` отсутствует или недоступен.

## 5. Легальные варианты получения актов (Оценка)

Ввиду наличия директивы `Disallow: /` в `robots.txt` на обоих ресурсах, сбор данных без согласования несет риски блокировки IP, правовых претензий и нестабильности пайплайна. Ниже представлены возможные варианты решения:

| Вариант | Описание | Плюсы | Минусы | Оценка |
|---|---|---|---|---|
| **Вариант 1: Официальный запрос в Cancelaria de Stat / STISC на доступ к `actelocale.gov.md`** | Направление официального запроса от юридического лица / исследовательской группы на предоставление доступа к API реестра или включение IP краулера в whitelist. | 1. 100% легальный статус.<br>2. Прямой доступ ко всей базе (22.8k актов) с актуальными метаданными и статусами.<br>3. Возможность пакетной выгрузки без нагрузки на веб-сервер. | Сроки согласования с госорганами могут составить от 15 до 30 дней. | **Рекомендуемый (Основной)** |
| **Вариант 2: Запрос в Primăria Municipiului Chișinău** | Запрос в Управление по связям с общественностью и информатизации Примэрии (Direcția generală administrare și digitalizare). | Прямой контакт с автором документов, возможность получения прямых дампов архивов до 2022 года. | Сама Примэрия перевела ведение базы на `actelocale.gov.md`, поэтому по современным актам они с высокой вероятностью перенаправят в Госканцелярию. | Вторичный (для архивов до 2022) |
| **Вариант 3: Партнёрство с Civic Tech организациями (например, Primăria Mea / IDIS Viitorul)** | Коллаборация с НПО, регулярно проводящими мониторинг решений CMC и имеющими налаженные контакты с муниципалитетом. | Быстрый старт, возможность получения уже агрегированных выборок по ключевым темам (бюджет, урбанизм, зонирование). | Общественные организации, как правило, собирают не полный корпус, а только резонансные решения. | Вспомогательный |
| **Вариант 4: Регулярный ручной/полуавтоматический экспорт через DataTables** | Запуск скрипта сдержанного сбора (1 запрос в 2–3 секунды) с указанием контактного `User-Agent` исследовательской команды. | Технически реализуемо немедленно через эндпоинт `search_request`. | Формальное несоответствие `robots.txt`, риск временной блокировки IP при превышении лимитов. | Только как временное решение для MVP |

## 6. Рекомендации для команды

1. **Фокусировать сбор современных актов не на `chisinau.md`, а на `actelocale.gov.md`**:
   - `chisinau.md` является лишь витриной-оберткой; парсинг его страниц дублирует данные и создает лишнюю нагрузку.
   - Все 22 850 актов Кишинэу централизованно хранятся в `actelocale.gov.md` под кодами APL `19323` (CMC) и `18413` (Примар).
2. **Инициировать официальное обращение (Вариант 1)**:
   - Подготовить письмо от имени проекта в Госканцелярию РМ с запросом на получение доступа к данным Реестра местных актов в исследовательских целях (создание семантического поиска и ИИ-ассистента для граждан).
3. **Для текущего MVP и тестирования пайплайна**:
   - Использовать уже скачанные и распарсенные данные из `data/parsed` (текущий корпус в проекте).
   - В краулере предусмотреть адаптер для `actelocale.gov.md` (на случай одобрения запроса или пакетного импорта).
4. **Для исторического архива (до 2022 года)**:
   - Если потребуется исторический срез решений CMC, закладывать обязательный этап OCR, так как муниципальный архив состоит из растровых сканов.
