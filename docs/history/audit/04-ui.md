# 4. Интерфейс: чат и админка

Смотрел все страницы админки и чат на компьютере (1440×900) и телефоне (390×844) против живого бэкенда.
Компоненты — shadcn/ui, AI Elements и spell; своих «самописных» карточек почти не осталось.

Под «выглядит шаблонно» (ИИ-слоп) имею в виду: декоративные элементы, которые не несут информации,
дублирование одних и тех же цифр в разных блоках, пустые блоки-заглушки и бодрые тексты пустых состояний.

---

## Админка

### U1. Категории показываются сырыми ключами — **средняя**
`admin/sources/page.tsx`: колонка «Категория» и подменю «Категория» выводят `urban_utilities`,
`transparency`, `city_hall` как есть, на всех трёх языках. Выглядит недоделанным.
**Решение:** подписи категорий в `admin-i18n.ts` (RO/RU/EN). **Сделано.**

### U2. Таблица источников не помещается на телефоне — **высокая для телефона**
Колонка статуса фиксированной ширины `w-60`, контейнер `overflow-hidden`: на 390 px статус обрезан,
остальное недоступно, горизонтальной прокрутки нет.
**Решение:** на узком экране статус без фиксированной ширины, название короче, контейнер с прокруткой как
подстраховка. **Сделано.**

### U3. Вопросы без ответа спрятаны внутри «Источников» — **средняя**
Блок стоит между строкой добавления ссылки и таблицей из 40 сайтов: его легко пропустить, а таблица уезжает
вниз. Это отдельная работа («чего не хватает в документах»), ей нужен свой пункт меню со счётчиком.
**Решение:** отдельная страница «Вопросы без ответа» в меню; кнопка «Добавить источник» ведёт на
«Источники» и ставит курсор в поле ссылки. **Сделано.**

### U4. Вкладки «Обработки» ломаются на телефоне — **средняя**
Шесть вкладок переносятся, последняя («остановлена») вылезает из подложки.
**Решение:** одна строка с горизонтальной прокруткой. **Сделано.**

### U5. «Оценки»: дубли и пустые блоки — **средняя (слоп)**
- «Полезно / не полезно» полосками повторяет две карточки над ними теми же числами и процентами.
- «Частые причины» всегда пустой белый блок: в чате нет способа указать причину (см. U7).
- График «по дням» при одном дне — большой пустой блок с «—».
- На телефоне три карточки идут столбиком по одной и занимают весь экран.
**Решение:** убрать полоски-дубль; причины показывать, только когда они есть, иначе короткая подсказка;
для графика — текст «появится, когда будут оценки за несколько дней»; на телефоне три карточки в ряд.
**Сделано.**

### U6. Пустые состояния в духе «Отлично!» — **низкая (слоп)**
«Дизлайков нет. Отлично!», «Нет ни одного вопроса без ответа. Отлично!» с иконкой в кружке — типичный
шаблон. Не мешает, оставил; при желании заменить на нейтральное «Дизлайков пока нет».

### Что уже хорошо
Скелетоны только на цифрах, вопросы без ответа строками с раскрытием, меню действий у обработок, один
список быстрых вопросов на все языки — это сделано днём и выглядит собранно.

## Чат

### U7. Дизлайк без причины — **средняя**
В чате только 👍/👎, хотя API принимает причины (`wrong`, `outdated`, `incomplete`, `wrong_source`,
`not_understood`) и админка показывает «Частые причины». Из-за этого админ видит «не полезно», но не знает,
что именно не так.
**Решение:** после 👎 под ответом появляются чипы причин (одно нажатие, можно несколько) — отправляются той
же оценкой (сервер перезаписывает оценку этого ответа). **Сделано.**

### Прочее
- Панель документа, свечение, «Думаю…», один значок на несколько предложений из одного документа — днём.
- На телефоне пустой экран без быстрых вопросов выглядит пусто, но это управляется из админки (закрепить).
